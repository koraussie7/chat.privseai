# n8n Featured Image Automation

This workflow automates _publishing an image generated by a separate image provider_ to the site's featured image URL. n8n does not generate images on its own: connect an image-generation API (or an image model you host) in the `Generate Image` HTTP Request node.

## Workflow

`Schedule Trigger → Read Prompt → Generate Image → Upload to image host → Update featured image`

It is intentionally configured for **manual execution only** until you add and test credentials. Do not enable a recurring schedule until a successful test has updated the preview image.

## Image host expectation

Use a host with a stable public URL (object storage/CDN). The upload node must return JSON containing `url`, for example:

```json
{ "url": "https://cdn.example.com/privseai/luna-featured.webp" }
```

For Git-managed deployment, point the final node to a protected GitHub workflow-dispatch endpoint (recommended) or a small authenticated deployment webhook. Do not put GitHub tokens in a public frontend or workflow export. The site can then update `CANDY_PRESETS`' Luna `avatarUrl` or `bannerUrl` from the committed asset. A CDN URL alone does not change the checked-in source URLs unless the app is configured to read the featured-image manifest.

## Install

1. n8n → **Workflows → Import from File** → import `privseai-featured-image.json`.
2. Configure `Generate Image` for your selected provider and attach credentials in n8n's credential store. Replace the example endpoint and request body.
3. Configure `Upload Image` with your private storage credentials, uploading the binary `image` and returning a public `url` field. Set up that storage node according to your provider's API.
4. Configure `Update Featured Image` to call an authenticated backend / GitHub workflow you control. Use n8n credentials or a secret manager; never hardcode tokens into this exported workflow.
5. Run manually and inspect each node's output. Verify image format, dimensions, content, public CDN URL, and site update before enabling a schedule.
6. After validation, enable the `Schedule Trigger` and set your desired cadence in n8n.

## Important

- Image-generation provider APIs vary. The workflow uses clearly marked placeholder URLs/bodies and is not production-ready until replaced.
- Keep generated content in line with your site's policies and use an adult, fictional, fully clothed character prompt.
- Configure provider billing limits, timeouts, retry limits, storage retention, and failure notifications before enabling recurring runs.
- The image refresh should publish a versioned URL (or invalidate CDN cache) to avoid stale browser caches.
